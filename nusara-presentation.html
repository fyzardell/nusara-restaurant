Jenis Relasi
One to One
users ↔ customers
Setiap user bertipe customer hanya memiliki 1 profil customer. Dijamin dengan unique() pada kolom user_id.
One to Many
orders → order_items
1 pesanan bisa memiliki banyak item. Juga berlaku: categories→menus, tables→sessions, orders→payments.
Many to Many
reservations ↔ tables
Melalui tabel pivot reservation_tables. 1 reservasi bisa menempati >1 meja, 1 meja bisa ada di >1 reservasi (waktu berbeda).
Snapshot Pattern
order_items menyimpan menu_name_snapshot & unit_price_snapshot agar histori harga tidak berubah meski menu diedit.

05 — Database: Kendala & Solusi
Database

Kendala Umum & Solusi

05 / 12
1
Unique Constraint Violation saat Seeding
SQLSTATE[23000]: UNIQUE constraint failed: categories.slug
Solusi
Migrasi sudah mengisi data kategori, seeder mencoba insert ulang. Gunakan where('slug')->first() + update jika ada (idempotent seeder). Jalankan migrate:fresh --seed hanya di development, bukan production.
2
Port 3306 Sudah Dipakai (Docker Conflict)
Can't start server: Address already in use on port 3306
Solusi
Container Docker lain (income_mysql) sudah memegang port 3306. Gunakan docker stop income_mysql atau ubah port MySQL aaPanel ke 3307 di /etc/my.cnf dan sesuaikan DB_PORT di .env.
3
Access Denied untuk User Database
SQLSTATE[1045]: Access denied for user 'nusara'@'localhost'
Solusi
User belum terdaftar di MySQL atau plugin autentikasi berbeda. Buat ulang user dengan IDENTIFIED WITH mysql_native_password BY 'password' dan pastikan GRANT ALL PRIVILEGES ON nusara.* TO 'nusara'@'127.0.0.1' dieksekusi.
4
Socket MySQL Tidak Ditemukan (aaPanel)
Can't connect through socket '/run/mysqld/mysqld.sock' (Errno 2)
Solusi
MySQL aaPanel menyimpan socket di /tmp/mysql.sock, bukan di path standar Debian. Buat symlink: ln -sf /tmp/mysql.sock /run/mysqld/mysqld.sock. Nonaktifkan PrivateTmp=false di systemd override.
5
N+1 Query Problem
SELECT * FROM menus WHERE category_id = ? (dipanggil 10x loop)
Solusi
Gunakan Eloquent eager loading: Menu::with(['category', 'images'])->get(). Tambahkan index pada kolom yang sering di-query (category_id, slug, order_status).
6
Data Harga Berubah Setelah Pesanan
order_items.price tidak sesuai harga saat pelanggan memesan
Solusi
Gunakan Snapshot Pattern: saat order dibuat, salin menu.name ke menu_name_snapshot dan menu.price ke unit_price_snapshot di tabel order_items. Data historis tetap akurat meski menu diedit.

06 — Backend: Gambaran Umum
Backend

Arsitektur Laravel 13 + Inertia.js

06 / 12
Framework & Arsitektur
Laravel 13.43 pada PHP 8.5 menggunakan pola MVC klasik. Request masuk melalui routes/web.php, diproses Controller, lalu dikembalikan lewat Inertia.js sebagai JSON props ke komponen React — tanpa endpoint API terpisah.
Role-Based Access
Sistem memiliki 4 role: admin, cashier, waiter, customer. Setiap role memiliki route group, controller, dan halaman React tersendiri. Middleware memastikan user hanya bisa mengakses area role-nya.
Payment Gateway (Midtrans)
Paket midtrans/midtrans-php ^2.6 terintegrasi untuk QRIS dan bank transfer. Webhook Midtrans mengirim notifikasi ke endpoint Laravel yang memperbarui status payments dan payment_transactions secara otomatis.

08 — Backend: Kendala & Solusi
Backend

Kendala Umum & Solusi

08 / 12
Composer TypeError PHP 8.5
TypeError: Silencer::call() — Argument #1 must be callable
Penyebab: chown & chgrp masuk disable_functions di php.ini aaPanel.
Solusi
Hapus fungsi dari disable_functions di php.ini, jalankan php -d disable_functions="" composer.phar install.
APP_KEY Belum di-generate
RuntimeException: No application encryption key specified
Penyebab: File .env tidak ada di server (di-ignore oleh git).
Solusi
Salin .env.example → .env lalu jalankan php artisan key:generate --force.
Route Cache Conflict
Target [App\Http\Controllers\XController] is not instantiable
Penyebab: Cache route lama setelah controller baru dibuat.
Solusi
Jalankan php artisan optimize:clear lalu php artisan route:cache setelah setiap perubahan controller.
CSRF Token Mismatch
419 — Page Expired: CSRF token mismatch
Penyebab: Form POST tanpa token CSRF atau session expired di production.
Solusi
Inertia otomatis mengirim CSRF. Pastikan SESSION_DOMAIN di .env sesuai domain produksi dan APP_URL benar (https).
Queue & Job Gagal
Job failed: No connection could be made
Penyebab: QUEUE_CONNECTION=database tapi tabel jobs belum ada atau session driver salah.
Solusi
Jalankan migrasi penuh agar tabel jobs, cache, sessions terbuat. Atau ganti ke QUEUE_CONNECTION=sync sementara.
open_basedir Restriction
Warning: fopen(): open_basedir restriction in effect
Penyebab: Fitur Anti-XSS aaPanel membatasi path akses PHP ke luar folder website.
Solusi
Matikan Anti-XSS (open_basedir) di pengaturan Website aaPanel → Site directory → unchecklist Anti-XSS attack.

10 — Frontend: Kendala & Solusi
Frontend

Kendala Umum & Solusi

10 / 12
1
Vite Asset Not Found setelah Deploy
Failed to load resource: /build/assets/app-xxx.js (404)
Solusi
File build tidak ter-upload ke VPS. Jalankan npm run build di server VPS setelah git pull. Pastikan folder public/build masuk git atau dijalankan di CI/CD pipeline.
2
Inertia Page Not Found
The Inertia page component "Admin/Dashboard" cannot be found
Solusi
Nama komponen harus persis sama (case-sensitive) antara Inertia::render('Admin/Dashboard') di Laravel dan nama file resources/js/Pages/Admin/Dashboard.tsx.
3
TypeScript Props Mismatch
Type error: Property 'menus' does not exist on type InertiaPageProps
Solusi
Definisikan interface TypeScript untuk setiap halaman: interface Props { menus: Menu[] } dan gunakan sebagai tipe parameter komponen. Pastikan nama props dari Laravel cocok.
4
Tailwind 4 Class Tidak Muncul
Styling tidak terapply — class ada di HTML tapi tidak ada di CSS output
Solusi
Tailwind 4 menggunakan @tailwindcss/vite bukan PostCSS tradisional. Pastikan plugin sudah ada di vite.config.js dan import di CSS menggunakan @import "tailwindcss".
5
React 19 Hydration Error
Hydration failed — server rendered HTML does not match client
Solusi
NUSARA tidak menggunakan SSR, jadi Inertia render sepenuhnya di client. Hindari akses window atau document langsung di render cycle — gunakan useEffect untuk kode browser-only.
6
State Tidak Persist saat Navigasi
Data form hilang saat berpindah halaman via Inertia link
Solusi
Gunakan useForm() dari Inertia untuk form management, bukan state React biasa. Untuk data global (user auth), akses melalui usePage().props.auth yang di-share via Inertia shared data.
