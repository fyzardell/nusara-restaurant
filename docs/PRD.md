# NUSARA Restaurant Management Website

**Product Requirements Document (PRD) — Final Draft v3.0**  
Modern Casual Dining · Indonesian Cuisine · Single Branch

## 1. Product Overview
NUSARA adalah website restoran yang menggabungkan customer-facing website dengan sistem operasional internal. Pelanggan dapat melihat menu, mencari menu best seller, menyimpan favorit, melakukan pemesanan Dine-in melalui QR meja, melakukan pemesanan Takeaway, dan melakukan reservasi. Staf mengelola menu, meja, reservasi, pesanan, pembayaran, serta status penyajian.

## 2. Brand Identity
- **Brand**: NUSARA — Indonesian Dining Experience
- **Mood**: Luxury, elegant, warm, modern, editorial
- **Colors**:
  - Burgundy: `#32151F` — primary
  - Ivory: `#F4EFE6` — background/light surface
  - Gold: `#B99A65` — accent
  - Espresso: `#211D1B` — dark surface/text
- **Typography**:
  - Heading: Cormorant Garamond
  - Body: DM Sans
  - Dashboard: Manrope

## 3. Technology Stack
- Backend: Laravel
- Frontend: React + TypeScript
- Bridge: Inertia.js
- Database: MySQL
- Temporary storage / cache: Redis
- Styling: Tailwind CSS
- UI Components: shadcn/ui
- Icons: Lucide React
- Forms: React Hook Form + Zod
- Build: Vite
